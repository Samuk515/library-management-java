# Library Management System

A Java console application to manage library books with borrow and return tracking.

## Features
- Add books with title and author
- Search books by title or author
- Borrow and return books
- Saves all data to a text file for persistence

## How to Run
1. Clone the repo
2. Open in your IDE
3. Run `Main.java`

## Tech Used
- Java
- File I/O
- OOP (Object Oriented Programming)
